# Utiliser FastAPI, HTMX et SQLite pour le MVP

Le MVP utilise FastAPI avec un rendu serveur leger, HTMX pour les interactions simples, SQLite pour le stockage applicatif et des connecteurs Python par source d'offres. Ce choix evite la complexite d'une SPA et d'une base serveur separee pour une application mono-utilisateur, tout en restant deployable proprement sur un VPS.
