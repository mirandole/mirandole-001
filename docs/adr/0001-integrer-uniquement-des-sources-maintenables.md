# Integrer uniquement des sources maintenables

L'application agrege des offres d'emploi depuis plusieurs sources, mais une source n'est integree que si elle fournit un acces autorise et techniquement stable, comme une API officielle, un flux public exploitable, un partenariat ou une page recuperable sans contournement. Ce choix retarde potentiellement l'integration de sources tres visibles comme LinkedIn ou Indeed, mais evite de fonder le produit sur des collectes fragiles ou susceptibles d'etre bloquees.
