# Isoler les sources par connecteurs normalises

Chaque source d'offres integree est implementee par un connecteur de source qui traduit son API ou flux vers un format commun de resultat d'offre. Les enrichissements transverses, comme les tags de competence et les niveaux d'experience ou de diplome, sont appliques apres cette normalisation afin d'eviter de dupliquer la logique dans chaque integration.
